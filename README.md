# 🍽️ 저메추 (오늘 뭐 먹지? 저녁 메뉴 추천)

> 결정 장애를 단 3초 만에 해결해 주는 토스(Toss) 스타일의 프리미엄 저녁 메뉴 추천 앱

---

## ✨ 주요 기능
- **🎲 3초 원터치 퀵 추천**: 카테고리별/상황별 스마트 추천
- **🎡 인터랙티브 룰렛 & 슬롯머신**: 박진감 넘치는 당첨 연출
- **🏆 16강 이상형 월드컵**: 승자독식 토너먼트 배틀
- **🔥 야근 위로 & 야식 모드**: 칼로리 폭탄 & 힐링 멘트 지원
- **🏢 직장인 맞춤 필터**: 배달/혼밥/회식/예산별 필터링
- **📱 PWA & Android 지원**: 웹 및 안드로이드 네이티브 앱 완벽 지원

---

## 🚀 GitHub Actions로 Android APK 다운로드하는 법

1. 이 저장소의 **[Actions]** 탭으로 이동합니다.
2. 실행된 **Build Android APK (저메추)** 워크플로우를 클릭합니다.
3. 페이지 하단 **Artifacts** 영역에서 `jomechu-app-debug.apk` 파일을 다운로드합니다.
4. 스마트폰으로 전송하거나 휴대폰 브라우저에서 다운로드하여 설치합니다.

---

# 브라우저에서 index.html을 열거나 정적 서버 실행
